# Cave Monkey Rescue

A pixelated platformer game built with HTML, CSS, and JavaScript. Rescue the baby monkeys in the cave!

## Play

Open index.html in your browser to play.

## Controls

- Arrow Keys / WASD: Move
- Space / Arrow Up: Jump

## Features

- Platformer physics (gravity, friction, jumping)
- Collectible baby monkeys
- Springs and bounce pads
- Sound effects
- Pixel art style

## Run locally

`ash
# Clone this repository
git clone https://github.com/your-username/monkey-rescue-game.git

# Open in browser

start index.html # Windows
xdg-open index.html # Linux
`
